Public product information and policy pages for the independent desktop studio.

Target account: `mirai-astra`. Target repository: `mirai-astra.github.io`.

Build with `node build.mjs` and verify with `node verify.mjs`. Source artwork and styling are in `assets/`. Publish only the top-level generated files in `dist/`, plus the generated README, to the repository root. Older nested files from an earlier local build are not publication inputs. No platform tokens, desktop app database or private application source is required.

Expected addresses after successful deployment:
- https://mirai-astra.github.io/
- https://mirai-astra.github.io/terms.html
- https://mirai-astra.github.io/privacy.html

GitHub Pages configuration: deploy from the `main` branch, repository root. The `.nojekyll` file preserves the static site without Jekyll processing. An actual TikTok URL-verification file can be added to the root when supplied by the portal.
